# Интерактивы: квизы и узлы

Статический сайт — работает на GitHub Pages без сервера.

- `medicina/` — квиз «Первая помощь»
- `travy/` — квиз «Травоведение»
- `uzly/` — узлы со схемами вязания (`uzly/?print` — печать QR-кодов узлов)
- `imena/` — база лесных имён «Байкальского Скаута» с поиском и заявками; данные хранятся в Supabase, запуск — `imena/SETUP.md`. Управление — `imena/admin.html` (в меню не показывается)

Квизы считают результат прямо в телефоне участника; на сервер ничего не отправляется. Исключение — «Лесные имена»: они читают базу и принимают заявки через Supabase.
QR-коды для печати — на главной странице, они строятся под адрес, на котором открыт сайт.
