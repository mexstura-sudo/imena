# Запуск «Лесных имён»

Около 20 минут. Нужны: почта и аккаунт GitHub, где лежит этот репозиторий.

Адреса после запуска:
- сайт для всех — `https://mexstura-sudo.github.io/quiz/imena/`
- управление — `https://mexstura-sudo.github.io/quiz/imena/admin.html` (в меню нет, ссылку знают только админы)

## 1. Создать проект в Supabase

1. Откройте supabase.com → **Start your project**, войдите через GitHub.
2. **New project**: название `lesnye-imena`, придумайте и сохраните пароль базы, регион **Central EU (Frankfurt)**, тариф Free. Карта не нужна.
3. Подождите 1–2 минуты, пока проект создаётся.

## 2. Создать таблицы и права

1. Слева **SQL Editor** → **New query**.
2. Откройте файл `imena/supabase/schema.sql`, скопируйте всё и вставьте.
3. В самом конце замените `ВАШ_EMAIL@example.com` на свою почту — она станет первым администратором.
4. Нажмите **Run**. Должно появиться «Success. No rows returned».
5. Проверка: **Table Editor** → таблица `names` — 66 записей.

Скрипт можно запускать повторно (например, после обновления) — данные не задвоятся.

## 3. Вставить ключи в config.js

1. Нажмите **Connect** вверху проекта (или **Project Settings → API Keys**).
2. Скопируйте **Project URL** (`https://xxxx.supabase.co`) и **Publishable key** (`sb_publishable_…`).
3. Вставьте их в `imena/config.js`.

Эти два значения публичные — их видно в коде сайта, и это нормально: всё защищено правами в базе.
**Secret key (`sb_secret_…`) никуда не вставлять и никому не показывать.**

## 4. Настроить вход для админов

**Authentication → URL Configuration**:
- **Site URL**: `https://mexstura-sudo.github.io/quiz/imena/admin.html`
- **Redirect URLs** → Add URL → то же самое.

Без этого ссылка из письма будет вести не туда.

## 5. Выложить на GitHub

1. github.com → репозиторий `quiz` → **Add file → Upload files**.
2. Перетащите из архива папку `imena` и файлы `index.html`, `README.md` (главная с новой карточкой).
3. **Commit changes**. Через 1–2 минуты GitHub Pages обновит сайт.

## 6. Проверить

1. Откройте сайт — должна появиться база из 66 имён.
2. Отправьте тестовую заявку с фото.
3. Откройте `admin.html`, введите свою почту, перейдите по ссылке из письма (на этом же устройстве).
4. Во вкладке **Заявки** одобрите или отклоните тестовую заявку.
5. Проверьте сайт с телефона через мобильный интернет и из сети школы — Supabase зарубежный, доступность стоит проверить заранее.

## Как пользоваться

- **Заявки** — перед одобрением можно поправить имя, ФИО, отряд, год и выбрать силуэт. Если такое лесное имя уже есть, появится предупреждение. При одобрении фото переносится в публичную папку, при отклонении — удаляется.
- **База** — поиск, правка любой записи, замена или удаление фото, удаление записи, ручное добавление.
- **Админы** — добавьте почту человека и отправьте ему ссылку на `admin.html`. Убрать доступ можно там же; себя удалить нельзя.

## Что нужно знать

- **Засыпание.** Бесплатный проект засыпает, если к базе неделю никто не обращался. Тогда сайт покажет «Не получилось загрузить базу». Разбудить: войти на supabase.com → проект → **Restore**. Пока сайт открывают хотя бы раз в неделю, он не засыпает.
- **Письма.** Встроенная почта Supabase отправляет лишь несколько писем в час. Для входа пары админов этого хватает. Если писем не хватит, в **Authentication → Emails** можно подключить свою почту (SMTP).
- **Фото.** Перед отправкой фото уменьшаются до 1200 px и перекодируются в JPEG — так стирается геометка и другие данные из файла. Лимит хранилища на бесплатном тарифе — 1 ГБ, это тысячи фото.
- **Спам.** Заявку может отправить любой — так и задумано. Если начнут приходить мусорные заявки, их проще удалять пачкой в **Table Editor → requests**; при необходимости можно добавить капчу.
- **Согласия.** Заявка с фото сохраняется с отметкой о согласии на публикацию (поле `photo_consent`). Для фото детей согласие даёт родитель — эта формулировка есть в форме.
